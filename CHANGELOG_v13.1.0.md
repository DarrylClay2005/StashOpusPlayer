# StashOpusPlayer v13.1.0 - Enhanced SynthWave Visualizer 🎵✨

## 🚀 Major Features

### Enhanced SynthWave Visualizer
- **Real-time Audio Integration**: Direct connection to Android's Visualizer API for live audio analysis
- **Advanced Visual Effects**: Neon grid animations, lightning bolts, particle systems, and ripple effects
- **Audio-Reactive Animations**: Effects that respond to music intensity (lightning on peaks, ripples on bass)
- **Interactive Seeking**: Touch the visualizer to seek to any position in the track
- **Customizable Effects**: All visual effects can be toggled on/off in settings

## 🎛️ Settings & Customization

### New Animation Controls
- **Lightning Effects**: Toggle dramatic lightning bolts during intense audio moments
- **Particle Systems**: Enable/disable floating particle animations
- **Ripple Effects**: Control circular ripple animations that react to bass frequencies  
- **Breathing Animation**: Subtle pulsing effect that makes the visualizer "breathe"
- **Color Shifting**: Dynamic color transitions that cycle through the spectrum
- **Animation Intensity**: Adjust the strength of all visual effects

### Live Updates
- All settings changes take effect immediately without restarting the app
- Preference changes are synchronized across the entire app
- Visual feedback when settings are modified

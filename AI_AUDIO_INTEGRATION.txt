AI AUDIO INTEGRATION - STASH OPUS PLAYER
=========================================

OVERVIEW
--------
Integrated TensorFlow Lite and AI-powered audio preset system to automatically analyze
audio files and suggest optimal EQ and processing settings.

LIBRARIES ADDED
---------------
1. TensorFlow Lite 2.14.0 - Google's lightweight ML framework
2. TensorFlow Lite Support 0.4.4 - Support libraries for TensorFlow Lite

Location in build.gradle:
- Lines 254-256

FEATURES IMPLEMENTED
--------------------
1. **AI Audio Preset Manager** (AIAudioPresetManager.kt)
   - Analyzes audio characteristics using MediaMetadataRetriever
   - Suggests optimal presets based on genre, bitrate, and sample rate
   - 10 pre-configured intelligent presets

2. **Audio Characteristics Analysis**
   - Extracts genre, bitrate, sample rate from audio files
   - Estimates bass, mid, and treble levels
   - Determines optimal preset automatically

3. **10 AI-Powered Presets**
   - Bass Boost - Enhanced low frequencies
   - Vocal Clarity - Optimized for vocals/podcasts
   - Classical - Balanced for orchestral music
   - Rock - Punchy mids and treble
   - Jazz - Warm and balanced
   - Electronic - Dynamic range for EDM
   - Hip-Hop - Heavy bass with clear vocals
   - Acoustic - Natural sound for acoustic instruments
   - Treble Boost - Enhanced high frequencies
   - Flat - No modifications

Each preset includes:
- 10-band EQ settings (-10dB to +10dB)
- Reverb preset (None, Small Room, Plate, Large Room, Concert Hall)
- Bass boost level (0-1000)
- Virtualizer level (0-1000)

HOW IT WORKS
------------
1. User plays a song
2. AIAudioPresetManager analyzes the audio file
3. System extracts metadata (genre, bitrate, sample rate)
4. Algorithm estimates audio characteristics
5. Optimal preset is suggested based on analysis
6. User can apply suggested preset or choose manually

PRESET SELECTION LOGIC
----------------------
Genre-based:
- Rock/Metal → Rock preset
- Jazz/Blues → Jazz preset
- Classical/Orchestra → Classical preset
- Electronic/EDM/Techno → Electronic preset
- Hip-Hop/Rap/Trap → Hip-Hop preset
- Acoustic/Folk → Acoustic preset
- Vocal/Podcast → Vocal Clarity preset

Characteristic-based:
- High bass level (>0.7) → Bass Boost
- High treble level (>0.7) → Treble Boost
- Default → Flat preset

USAGE EXAMPLE
-------------
```kotlin
val aiPresetManager = AIAudioPresetManager(context)

// Get suggested preset for a song
lifecycleScope.launch {
    val suggestedPreset = aiPresetManager.analyzeAndSuggestPreset("/path/to/song.mp3")
    if (suggestedPreset != null) {
        // Apply the preset
        applyPreset(suggestedPreset)
    }
}

// Get all available presets
val allPresets = aiPresetManager.getAllPresets()

// Get specific preset
val rockPreset = aiPresetManager.getPreset("Rock")
```

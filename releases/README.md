## 📱 Quick Install

### **Option 1: Direct Download**
1. Navigate to the [latest release folder](v8.1.5/)
2. Download either:
   - **Debug APK** (recommended for testing) 
   - **Release APK** (production ready)
3. Enable "Unknown Sources" on your Android device
4. Install the APK and enjoy!

### **Option 2: ADB Install** 
```bash
# Debug version
adb install -r releases/v8.1.5/StashOpusPlayer-v8.1.5-debug.apk

# Release version  
adb install -r releases/v8.1.5/StashOpusPlayer-v8.1.5-release.apk
```

## 📝 Installation Notes

### **First Time Install**
1. **Enable Unknown Sources** in Android Settings → Security
2. **Download APK** from this repository  
3. **Install** by tapping the downloaded file
4. **Grant permissions** when prompted
5. **Start downloading** real YouTube audio!

### **Updating from Previous Version**
- **Same signature**: Update will install over existing app
- **Different signature**: Uninstall old version first
- **Settings preserved**: Your preferences will be maintained

## 🎵 How to Use

1. **Open StashOpusPlayer**
2. **Search or paste** YouTube URL
3. **Select audio format** (MP3, M4A, etc.)
4. **Choose download location**
5. **Tap download** - watch for "Pending" status
6. **Wait for completion** - you'll get real YouTube audio!

**That's it! No external services, no demo files, just real YouTube downloads.** 🎉

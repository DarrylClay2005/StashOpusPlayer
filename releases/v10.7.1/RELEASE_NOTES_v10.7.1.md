# StashOpusPlayer v10.7.1 - Crossfade & Audio Settings Fixes

What's new

- Crossfade fix: crossfade now correctly follows shuffle order by using nextMediaItemIndex.
- Faster effect application: ensured app volume and effects are re-applied on state changes and item transitions.
- Reliability: equalizer/reverb rebind more defensively when the audio session changes.

Notes

- This is a patch release to improve playback transitions and effect responsiveness.
- If you had crossfade enabled previously, you should hear smoother transitions in shuffle mode.
